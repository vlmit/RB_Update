Для компиляции расширений требуется:
1. Установленная Visual Studio 2019 версии 16.8 или позже. Возможна установка бесплатной Community Edition.
2. Если используется другая IDE, помимо Visual Studio, то потребуется также установить .NET SDK 5.0.x последней доступной версии: https://dotnet.microsoft.com/download/dotnet/5.0
3. Для сборки расширений desktop-клиента и выполнении тестов из проекта Tessa.Test.Windows рекомендуется использовать Visual Studio 2022, или дополнительно установить .NET SDK 6.0.x последней доступной версии (если установлена Visual Studio 2022, то отдельно устанавливать SDK не требуется): https://dotnet.microsoft.com/download/dotnet/6.0
   Обратитесь к разделу документации за информацией по использованию Visual Studio 2019: https://mytessa.ru/docs/3.6/adm/install/troubleshooting/#buildExtensions

Для развёртывания веб-сервиса на IIS требуется установить .NET Runtime & Hosting Bundle версии 5.0.5 или старше:
https://dotnet.microsoft.com/download/dotnet/5.0
